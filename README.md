Seaborn Data Visualization

A hands-on Seaborn Data Visualization practice project focused on learning statistical and exploratory data visualization techniques using Python. This repository contains practical exercises using the Penguins dataset and covers a wide range of visualization methods, customization techniques, and relationship analysis.

📌 Project Overview

This project is created to build a strong foundation in Data Visualization and Exploratory Data Analysis (EDA) using Seaborn.

The notebook explores different types of plots to understand:

Data distributions
Relationships between variables
Categorical comparisons
Statistical patterns
Correlations
Individual observations
Multi-variable relationships
Data density
Visualization styling and customization
